모든 현대 프로그래밍 언어의 뿌리를 찾아가다 보면 결국 C를 만나게 됩니다.  
Python, Java, C++, 심지어 게임 엔진의 코어도 C로 짜여 있습니다.  
"왜 C부터 배우냐"는 질문에 대한 답은 하나입니다 — **컴퓨터가 실제로 무엇을 하는지 눈으로 보여주는 언어이기 때문입니다.**

---

## C란 무엇인가

C는 1972년 벨 연구소의 데니스 리치(Dennis Ritchie)가 만든 언어입니다.  
원래 목적은 **Unix 운영체제를 만들기 위한 도구**였습니다.

C의 특징을 한 문장으로 요약하면 이렇습니다.

> 하드웨어에 가장 가까운 고수준 언어

- **빠릅니다** — 컴파일러가 기계어로 직접 번역하기 때문입니다
- **작습니다** — 언어 자체에 내장된 기능이 거의 없습니다 (직접 만들어야 합니다)
- **투명합니다** — 메모리에 무슨 일이 일어나는지 직접 제어합니다

이 세 가지가 C를 배우기 어렵게 만들기도 하지만, 동시에 C를 배우고 나면 다른 언어가 쉬워지는 이유이기도 합니다.

## 첫 번째 프로그램: Hello, World!

관습적으로 모든 프로그래밍 입문은 화면에 `Hello, World!`를 출력하는 것으로 시작합니다.

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}
```

한 줄씩 분해해 보겠습니다.

### `#include <stdio.h>`

`#include`는 **다른 파일을 이 파일에 포함시키라**는 지시어입니다.  
`stdio.h`는 **Standard Input/Output**의 약자로, `printf`나 `scanf` 같은 입출력 함수들이 정의된 헤더 파일입니다.

C는 언어 자체에 출력 기능이 없습니다. printf도 누군가 만들어 놓은 함수를 빌려 쓰는 것입니다.

### `int main(void)`

모든 C 프로그램은 `main` 함수에서 시작합니다.  
운영체제가 프로그램을 실행할 때 "main이라는 이름의 함수부터 실행해"라고 약속이 되어 있습니다.

- `int` — 이 함수가 **정수를 반환한다**는 의미입니다
- `void` — **아무 입력도 받지 않는다**는 의미입니다

### `printf("Hello, World!\n");`

`printf`는 화면에 글자를 출력하는 함수입니다.  
`\n`은 **줄바꿈**을 의미하는 이스케이프 시퀀스입니다.

### `return 0;`

main 함수가 `0`을 반환하면 운영체제에 **"프로그램이 정상적으로 끝났습니다"**라고 알리는 것입니다.  
0이 아닌 값을 반환하면 오류가 발생했다는 신호입니다.

### 컴파일하고 실행하기

```bash
gcc hello.c -o hello    # 컴파일: hello.c → hello(실행파일)
./hello                 # 실행
```

```
Hello, World!
```

## 변수와 자료형

컴퓨터는 모든 것을 **메모리**에 저장합니다. 변수는 메모리의 특정 공간에 이름을 붙인 것입니다.

```c
int age = 25;
```

이 한 줄이 하는 일을 따져보면 이렇습니다.

1. 정수(`int`)를 저장할 공간(4바이트)을 메모리에 확보합니다
2. 그 공간의 이름을 `age`라고 붙입니다
3. 그 공간에 `25`를 저장합니다

### 기본 자료형

| 자료형 | 크기 | 저장하는 것 | 예시 |
|---|---|---|---|
| `int` | 4바이트 | 정수 | `-2147483648 ~ 2147483647` |
| `double` | 8바이트 | 실수(소수점) | `3.14`, `-0.001` |
| `char` | 1바이트 | 문자 하나 | `'A'`, `'z'`, `'3'` |
| `float` | 4바이트 | 실수(정밀도 낮음) | `3.14f` |

> **왜 int가 4바이트인가?**  
> 4바이트 = 32비트 = 2³² = 약 42억 가지의 숫자를 표현할 수 있습니다.  
> 음수까지 포함하면 약 -21억 ~ +21억입니다.

```c
#include <stdio.h>

int main(void) {
    int    score   = 95;
    double pi      = 3.14159;
    char   grade   = 'A';

    printf("점수: %d\n", score);
    printf("파이: %f\n", pi);
    printf("등급: %c\n", grade);

    return 0;
}
```

`printf`에서 `%d`, `%f`, `%c`는 **서식 지정자**입니다.  
"이 자리에 어떤 타입의 값을 넣을지"를 지정합니다.

| 서식 지정자 | 타입 |
|---|---|
| `%d` | int (정수) |
| `%f` | double, float (실수) |
| `%c` | char (문자) |
| `%s` | 문자열 |
| `%lf` | double (scanf에서) |

## 사용자 입력 받기: scanf

`printf`가 출력이라면, `scanf`는 입력입니다.

```c
#include <stdio.h>

int main(void) {
    int age;

    printf("나이를 입력하세요: ");
    scanf("%d", &age);           // & 에 주목!

    printf("입력한 나이: %d\n", age);

    return 0;
}
```

`&age`에서 `&`는 **주소 연산자**입니다.  
`scanf`는 "어느 메모리 공간에 값을 넣을지" 주소가 필요합니다.  
`age`는 값 자체이고, `&age`는 age가 저장된 메모리의 위치입니다.

이것이 처음에는 생소하지만, C의 핵심 개념인 **포인터**와 연결됩니다. 지금은 "scanf에는 변수 앞에 &를 붙인다"고 기억하세요.

## 간단한 계산기 만들기

지금까지 배운 것으로 실용적인 프로그램을 만들어 보겠습니다.

```c
#include <stdio.h>

int main(void) {
    double a, b;
    char op;

    printf("계산식을 입력하세요 (예: 3.5 + 2.1): ");
    scanf("%lf %c %lf", &a, &op, &b);

    if (op == '+') {
        printf("결과: %.2f\n", a + b);
    } else if (op == '-') {
        printf("결과: %.2f\n", a - b);
    } else if (op == '*') {
        printf("결과: %.2f\n", a * b);
    } else if (op == '/') {
        if (b == 0) {
            printf("오류: 0으로 나눌 수 없습니다.\n");
        } else {
            printf("결과: %.2f\n", a / b);
        }
    } else {
        printf("알 수 없는 연산자입니다.\n");
    }

    return 0;
}
```

```
계산식을 입력하세요 (예: 3.5 + 2.1): 10.0 / 3.0
결과: 3.33
```

`%.2f`는 소수점 아래 2자리까지 출력하라는 의미입니다.

## 정리

이번 글에서 배운 것들입니다.

- C는 하드웨어에 가깝고 빠른 언어이며, 모든 현대 언어의 조상입니다
- 모든 C 프로그램은 `main` 함수에서 시작합니다
- `printf`로 출력하고, `scanf`로 입력받습니다
- 변수는 타입과 함께 선언하며, 타입마다 메모리 크기가 다릅니다
- `scanf`에서는 변수 앞에 `&`를 붙여 주소를 전달합니다

다음 글에서는 **조건문과 반복문**을 다루겠습니다.  
컴퓨터가 판단하고 반복하는 방법을 이해하면 비로소 실제 프로그램처럼 느껴지기 시작합니다.
