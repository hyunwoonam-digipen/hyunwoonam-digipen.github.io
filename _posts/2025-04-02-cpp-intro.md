C를 배우고 나면 자연스럽게 만나는 언어가 C++입니다.  
이름 자체가 C에 `++`(증가 연산)을 붙인 것으로, **"C보다 하나 더 나아간 언어"**라는 의미를 담고 있습니다.  
C++은 C의 모든 것을 포함하면서, **객체지향 프로그래밍(OOP)**이라는 강력한 개념을 추가했습니다.

---

## C와 C++의 차이

C++은 C의 상위 집합(superset)입니다. 즉, 대부분의 C 코드는 C++에서도 그대로 동작합니다.

하지만 C++이 추가한 것들이 있습니다.

| 개념 | C | C++ |
|---|---|---|
| 클래스 (Class) | ❌ | ✅ |
| 상속 (Inheritance) | ❌ | ✅ |
| 오버로딩 (Overloading) | ❌ | ✅ |
| 참조자 (Reference) | ❌ | ✅ |
| `cin` / `cout` | ❌ | ✅ |
| `new` / `delete` | ❌ | ✅ |
| 템플릿 (Template) | ❌ | ✅ |

이 중 가장 핵심은 **클래스**입니다. 클래스가 무엇인지 이해하면 C++의 절반을 이해한 것입니다.

## Hello, World! in C++

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

C의 `printf` 대신 `cout`을 사용합니다. 비교해 보면 이렇습니다.

| | C | C++ |
|---|---|---|
| 헤더 | `#include <stdio.h>` | `#include <iostream>` |
| 출력 | `printf("Hello\n")` | `std::cout << "Hello" << std::endl` |
| 입력 | `scanf("%d", &x)` | `std::cin >> x` |

`<<`는 **스트림 삽입 연산자**입니다. "cout이라는 출력 스트림에 이 값을 밀어넣어라"는 의미입니다.

### `std::` 는 무엇인가

`std`는 **namespace(네임스페이스)**입니다. 쉽게 말해 함수들을 묶어놓은 폴더입니다.  
`cout`과 `endl`은 `std`라는 폴더 안에 들어있기 때문에 `std::cout`, `std::endl`로 사용합니다.

매번 `std::` 쓰기 번거롭다면 이렇게 선언할 수 있습니다.

```cpp
#include <iostream>
using namespace std;    // 이제부터 std:: 생략 가능

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

> **주의:** `using namespace std;`는 편하지만 대규모 프로젝트에서는 이름 충돌을 일으킬 수 있습니다. 지금은 편의상 사용하되, 나중에는 필요한 것만 선언하는 습관을 들이세요.

## 참조자 (Reference)

C++이 C에 추가한 개념 중 입문에서 바로 마주치는 것이 **참조자**입니다.

```cpp
int a = 10;
int& ref = a;   // ref는 a의 별명(참조자)

ref = 20;       // ref를 바꾸면 a도 바뀜

cout << a;      // 출력: 20
```

참조자는 **변수에 별명을 붙이는 것**입니다.  
`ref`와 `a`는 같은 메모리 공간을 가리킵니다.

이것이 함수에서 진짜 유용해집니다.

```cpp
// C 방식: 포인터로 값 변경
void swap_c(int* a, int* b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

// C++ 방식: 참조자로 값 변경 (훨씬 읽기 쉽다)
void swap_cpp(int& a, int& b) {
    int tmp = a;
    a = b;
    b = tmp;
}

int main() {
    int x = 1, y = 2;
    swap_cpp(x, y);
    cout << x << " " << y;   // 출력: 2 1
}
```

## 함수 오버로딩 (Function Overloading)

C에서는 같은 이름의 함수를 두 번 정의할 수 없습니다.  
C++에서는 **매개변수가 다르면** 같은 이름을 여러 번 사용할 수 있습니다.

```cpp
#include <iostream>
using namespace std;

// 세 가지 print 함수 — 이름은 같지만 받는 타입이 다름
void print(int x) {
    cout << "정수: " << x << endl;
}

void print(double x) {
    cout << "실수: " << x << endl;
}

void print(string s) {
    cout << "문자열: " << s << endl;
}

int main() {
    print(42);          // → 정수: 42
    print(3.14);        // → 실수: 3.14
    print("안녕하세요"); // → 문자열: 안녕하세요
}
```

컴파일러가 전달된 인자의 타입을 보고 자동으로 맞는 함수를 호출합니다. 이를 **오버로딩 해석(overload resolution)**이라 합니다.

## 클래스 (Class) — C++의 핵심

클래스는 **데이터(변수)와 기능(함수)을 하나로 묶는 설계도**입니다.

현실에서 '학생'을 프로그램으로 표현한다고 생각해 봅시다.

- 학생은 **이름**, **나이**, **점수** 같은 정보를 가집니다 → **멤버 변수**
- 학생은 **공부하다**, **성적 조회** 같은 행동을 합니다 → **멤버 함수**

```cpp
#include <iostream>
#include <string>
using namespace std;

class Student {
public:                    // public: 외부에서 접근 가능
    string name;
    int    age;
    double score;

    // 생성자: 객체가 만들어질 때 자동으로 호출
    Student(string n, int a, double s) {
        name  = n;
        age   = a;
        score = s;
    }

    // 멤버 함수
    void introduce() {
        cout << "이름: " << name
             << ", 나이: " << age
             << ", 점수: " << score << endl;
    }

    string getGrade() {
        if (score >= 90) return "A";
        if (score >= 80) return "B";
        if (score >= 70) return "C";
        return "F";
    }
};

int main() {
    // 클래스로부터 객체(인스턴스) 생성
    Student s1("김철수", 20, 92.5);
    Student s2("이영희", 21, 78.0);

    s1.introduce();   // 이름: 김철수, 나이: 20, 점수: 92.5
    s2.introduce();   // 이름: 이영희, 나이: 21, 점수: 78

    cout << s1.name << "의 학점: " << s1.getGrade() << endl;  // A
    cout << s2.name << "의 학점: " << s2.getGrade() << endl;  // C
}
```

### 클래스 vs 구조체

C의 `struct`와 비슷해 보이지만, 결정적인 차이가 있습니다.

| | struct (C) | class (C++) |
|---|---|---|
| 함수 포함 | ❌ | ✅ |
| 접근 제어 | ❌ | ✅ (public/private) |
| 상속 | ❌ | ✅ |
| 기본 접근 | — | private |

## 접근 제어: public과 private

클래스의 강력한 기능 중 하나는 **외부에서 함부로 건드리지 못하게** 막는 것입니다.

```cpp
class BankAccount {
private:                   // 외부에서 직접 접근 불가
    double balance;

public:
    BankAccount(double initial) {
        balance = initial;
    }

    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    bool withdraw(double amount) {
        if (amount > balance) {
            cout << "잔액 부족" << endl;
            return false;
        }
        balance -= amount;
        return true;
    }

    double getBalance() {
        return balance;
    }
};

int main() {
    BankAccount account(10000);

    // account.balance = -99999;  ❌ 컴파일 오류! private이라 접근 불가
    account.deposit(5000);
    account.withdraw(3000);

    cout << "잔액: " << account.getBalance() << endl;  // 12000
}
```

`balance`를 `private`으로 막아두면, 잔액을 직접 조작하는 것을 원천 차단합니다.  
이렇게 내부 구현을 숨기는 것을 **캡슐화(Encapsulation)**라고 합니다. 객체지향의 핵심 원칙 중 하나입니다.

## 정리

C++에서 처음 만나는 핵심 개념들을 정리했습니다.

- `cout / cin`으로 C보다 직관적인 입출력이 가능합니다
- **참조자(`&`)**를 사용하면 포인터 없이도 값을 직접 다룰 수 있습니다
- **오버로딩**으로 같은 이름의 함수를 다른 타입으로 여러 개 만들 수 있습니다
- **클래스**는 데이터와 함수를 하나로 묶은 설계도입니다
- `public / private`으로 외부 접근을 제어합니다 — 이것이 **캡슐화**입니다

다음 글에서는 **상속(Inheritance)**과 **다형성(Polymorphism)**을 다룹니다.  
클래스가 왜 진짜로 강력한지는 상속을 보고 나서야 느껴집니다.
